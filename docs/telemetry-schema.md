# SwasthyaEdge (VitalsSync) Telemetry Schema Specification

This document provides the definitive specification of the real physical telemetry generated by the ESP8266 microcontroller node (`hardware/vitalsync_esp8266/vitalsync_esp8266.ino`) and consumed by the Node.js backend (`backend/server.js`).

---

## 1. Physical Hardware Sensor Suite & Pin Configuration

| Sensor / Module | Hardware Interface | NodeMCU Pin | ESP8266 GPIO | Physical Phenomenon Measured |
| :--- | :--- | :--- | :--- | :--- |
| **DHT11** | Single-bus Digital | **D5** | GPIO 14 | Ambient air temperature and relative humidity |
| **BMP280** | I2C (addr `0x76`) | **D2 (SDA), D1 (SCL)** | GPIO 4, GPIO 5 | Ambient barometric pressure & sensor temperature |
| **AD8232 ECG** | Analog + 2 Digital | **A0, D6, D7** | A0, GPIO 12, GPIO 13 | A0 = ECG analog potential; D6 = Lead-Off+; D7 = Lead-Off- |
| **MAX30100** | I2C (addr `0x57`) | **D2 (SDA), D1 (SCL)** | GPIO 4, GPIO 5 | Optical photodiode raw reflection counts (Infrared & Red) |
| **MQ-135** | Digital Comparator | **D0** | GPIO 16 | Gas presence comparator (LOW = Gas Alert, HIGH = Normal) |
| **MPU6050** | I2C (addr `0x68`) | **D2 (SDA), D1 (SCL)** | GPIO 4, GPIO 5 | 3-axis accelerometer and 3-axis gyroscope motion data |
| **NEO-6M/8M GPS** | SoftwareSerial UART | **D3 (RX), D4 (TX)** | GPIO 0, GPIO 2 | NMEA GPS satellite tracking and position fix |
| **SSD1306 OLED** | I2C (addr `0x3C`) | **D2 (SDA), D1 (SCL)** | GPIO 4, GPIO 5 | 128x64 local diagnostic status screen |

## 2. Firmware Output Payload Schema (`GET /data` & `POST /api/telemetry/esp8266`)

The ESP8266 firmware constructs a compact JSON payload via `buildTelemetryJson()` and transmits it every 1000ms:

```json
{
  "ip": "192.168.1.105",
  "deviceId": "ESP8266-001",
  "patientId": 1,
  "dhtTemp": 28.50,
  "humidity": 62.00,
  "bmpTemp": 28.30,
  "pressure": 1008.40,
  "ecg": 512,

  "loMinus": 0,
```

## 3. Critical Medical & Physical Sensor Limitations

The following limitations are strictly enforced in both the firmware and backend normalization logic:

### 3.1 MAX30100 Raw Optical IR / RED are NOT Heart Rate or SpO2
- The values `maxIR` and `maxRED` represent raw electrical charges accumulated on the MAX30100 photodiode during optical sampling.
- **They are NOT blood oxygen saturation (SpO2 %)**: Calculating clinical SpO2 requires extracting AC and DC pulsatile components ($R = \frac{AC_{red}/DC_{red}}{AC_{ir}/DC_{ir}}$) and indexing an experimentally calibrated calibration curve.
- **They are NOT Heart Rate (BPM)**: Calculating pulse rate requires high-order bandpass filtering (0.5 Hz – 5.0 Hz) and adaptive peak-detection algorithms.
- **Backend Rule**: `backend/server.js` explicitly sets `heartRate = null` and `spo2 = null` rather than fabricating synthetic values.

### 3.2 DHT11 and BMP280 Temperatures are NOT Body Temperature
- Both DHT11 and BMP280 are **ambient environmental sensors** mounted on or near the circuit board.
- They measure the surrounding room temperature and circuit thermal dissipation (typically 20°C–32°C).
- **They do NOT measure core human body temperature**: Core body temperature requires a calibrated medical contact thermistor, tympanic IR sensor, or clinical axillary probe.
- **Backend Rule**: The backend labels this value as ambient room temperature and converts it to display Fahrenheit ($T_F = T_C \times 1.8 + 32$), but does NOT claim it is physiological core body temperature.

### 3.3 MQ-135 Digital Signal is NOT a Calibrated AQI Value
- The MQ-135 on the ESP8266 is wired via digital output pin `D0` to a generic onboard comparator with an analog potentiometer.
- **It is NOT an Air Quality Index (AQI)** or a calibrated Parts-Per-Million (PPM) concentration of $CO_2$, $NH_3$, or Benzene.
- It is a purely binary comparator threshold: `0` (LOW) indicates gas presence exceeding the manual potentiometer threshold, and `1` (HIGH) indicates ambient air.

### 3.4 AD8232 ECG Raw ADC Values are NOT Heart Rate (BPM)
- The value `ecg` read from analog pin `A0` (0–1023) represents instantaneous differential biopotential voltage across the right arm, left arm, and right leg electrodes.
- **It is NOT Heart Rate**: Heart rate extraction requires Pan-Tompkins QRS wave detection or R-peak thresholding over a 10-to-30 second window.
- The raw ADC value is suitable for plotting continuous rhythm strips, but cannot be presented as a BPM metric.

### 3.5 Blood Pressure (NIBP) is Completely Absent
- The hardware suite contains **no blood pressure cuff, air bladder, pump, or pressure transducer**.
- The backend explicitly outputs `bpSys: null, bpDia: null, bp: null`.
- The frontend renders `Unavailable (No Sensor)` whenever hardware telemetry is active.

## 5. SQLite Database Schema Mapping (`sensor_logs`)

When persisted to SQLite, the normalized payload is inserted into table `sensor_logs` with the following column mappings:

| Table Column | Source Field in Normalized Payload | SQLite Data Type | Constraints / Defaults |
| :--- | :--- | :--- | :--- |
| `id` | Auto-incremented primary key | `INTEGER` | `PRIMARY KEY AUTOINCREMENT` |
| `patient_id` | `patientId` | `INTEGER` | Foreign key referencing `patients(id)` |
| `hr` | `heartRate` (null) | `INTEGER` | `DEFAULT NULL` |
| `bp_sys` | `bpSys` (null) | `INTEGER` | `DEFAULT NULL` |
| `bp_dia` | `bpDia` (null) | `INTEGER` | `DEFAULT NULL` |
| `spo2` | `spo2` (null) | `INTEGER` | `DEFAULT NULL` |
| `temp` | `temp` (Display °F) | `REAL` | `DEFAULT NULL` |
| `timestamp` | `timestamp` (Unix epoch ms) | `INTEGER` | Not null |
| `health_score` | `healthScore` (0–100) | `INTEGER` | `DEFAULT NULL` |
| `humidity` | `humidity` (% RH) | `REAL` | `DEFAULT NULL` |
| `pressure` | `pressure` (hPa) | `REAL` | `DEFAULT NULL` |
| `ecg_val` | `ecg.value` (ADC 0–1023) | `INTEGER` | `DEFAULT NULL` |
| `mq135` | `mq135` (`"NORMAL"` / `"ALERT"`) | `TEXT` | `DEFAULT NULL` |
| `gps_lat` | `gps.latitude` | `REAL` | `DEFAULT NULL` |
| `gps_lng` | `gps.longitude` | `REAL` | `DEFAULT NULL` |
| `raw_payload` | `JSON.stringify(normalizedPayload)`| `TEXT` | `DEFAULT NULL` |
| `dht_temp` | `dhtTemp` (°C) | `REAL` | `DEFAULT NULL` |
| `bmp_temp` | `bmpTemp` (°C) | `REAL` | `DEFAULT NULL` |
| `max_ir` | `maxIR` (16-bit count) | `INTEGER` | `DEFAULT NULL` |
| `max_red` | `maxRED` (16-bit count) | `INTEGER` | `DEFAULT NULL` |
| `device_ip` | `deviceIp` | `TEXT` | `DEFAULT NULL` |
