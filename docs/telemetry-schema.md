# SWASTHYAEDGE Hardware Telemetry Schema Specification

## 1. Overview & Data Flow

This document provides the definitive specification of physical telemetry generated by the ESP8266 microcontroller node (`hardware/vitalsync_esp8266/vitalsync_esp8266.ino`), ingested and normalized by the Node.js backend (`backend/services/telemetry.service.js`), persisted to SQLite (`sensor_logs`), and broadcast to clinical dashboards via Socket.IO.

```
ESP8266 NodeMCU
      ↓  (HTTP POST /api/telemetry/esp8266 or /data background poller)
Backend Ingestion Pipeline
      ↓  (Validator Middleware: HTTP 400 on malformed payloads)
Canonical Normalizer (`telemetryNormalizer.js`)
      ↓  (Zero-fabrication enforcement)
SQLite Database (`sensor_logs`, `devices`, `alerts`)
      ↓  (Asynchronous non-blocking HTTP bridge)
AI Engine (`POST ${AI_ENGINE_URL}/predict` or `/analyze`)
      ↓  (Real-time broadcast: global + patient room)
Socket.IO Dashboard Clients
```

## 2. Physical Hardware Sensor Suite & Pin Configuration

| Sensor / Module | Hardware Interface | NodeMCU Pin | ESP8266 GPIO | Physical Phenomenon Measured |
| :--- | :--- | :--- | :--- | :--- |
| **DHT11** | Single-bus Digital | **D5** | GPIO 14 | Ambient air temperature and relative humidity |
| **BMP280** | I2C (addr `0x76`) | **D2 (SDA), D1 (SCL)** | GPIO 4, GPIO 5 | Ambient barometric pressure & sensor temperature |
| **AD8232 ECG** | Analog + 2 Digital | **A0, D6, D7** | A0, GPIO 12, GPIO 13 | A0 = ECG analog potential; D6 = Lead-Off+; D7 = Lead-Off- |
| **MAX30100** | I2C (addr `0x57`) | **D2 (SDA), D1 (SCL)** | GPIO 4, GPIO 5 | Optical photodiode raw reflection counts (Infrared & Red) |
| **MQ-135** | Digital Comparator | **D0** | GPIO 16 | Gas presence comparator (LOW / 0 = Gas Alert, HIGH / 1 = Normal) |
| **MPU6050** | I2C (addr `0x68`) | **D2 (SDA), D1 (SCL)** | GPIO 4, GPIO 5 | 3-axis accelerometer and 3-axis gyroscope motion data |
| **NEO-6M GPS** | Hardware UART Serial | **RX / TX** | GPIO 3, GPIO 1 | NMEA satellite positioning, latitude, longitude, and fix |

## 3. Ingestion Format (ESP8266 Payload)

The backend accepts both flat payloads (from ESP8266 `/data` or `/api/hardware/test-pulse`) and nested telemetry objects.

### Required Identity Fields
- `deviceId` (string, required): Hardware identifier (e.g. `"ESP8266-001"`).
- `patientId` (number, optional): Patient ID. If omitted, falls back to the database-mapped device assignment.

### Supported Sensor Keys

| Key | Type | Description | Unit / Range |
| :--- | :--- | :--- | :--- |
| `dhtTemp` | `number` | DHT11 Ambient Temperature | °C |
| `humidity` | `number` | DHT11 Relative Humidity | % |
| `bmpTemp` | `number` | BMP280 Ambient / Case Temperature | °C |
| `pressure` | `number` | BMP280 Barometric Pressure | hPa |
| `ecg` | `number` or `object` | AD8232 ECG Raw Analog Waveform | 0 – 1023 |
| `loPlus` | `number` or `boolean` | Lead-Off Plus detection | 0 = OK, 1 = Lead Off |
| `loMinus` | `number` or `boolean` | Lead-Off Minus detection | 0 = OK, 1 = Lead Off |
| `mq135` | `number` or `string` | MQ-135 Hazardous Gas / Smoke | 0 / `'ALERT'` = Alert, 1 / `'NORMAL'` = Normal |
| `accX`, `accY`, `accZ` | `number` | MPU6050 3-Axis Accelerometer | Raw LSB |
| `gyroX`, `gyroY`, `gyroZ`| `number` | MPU6050 3-Axis Gyroscope | Raw LSB |
| `maxFound` | `number` or `boolean` | MAX30100 I2C detection status | 0 / 1 |
| `maxIR` | `number` | MAX30100 Raw Optical Infrared Signal | 16-bit counts |
| `maxRED` | `number` | MAX30100 Raw Optical Red Signal | 16-bit counts |
| `gpsSat` | `number` | NEO-6M Satellites in view | Integer count |
| `gpsFix` | `number` or `boolean` | GPS Valid Fix status | 0 / 1 |
| `gpsLat` | `number` | Latitude | Decimal degrees |
| `gpsLng` | `number` | Longitude | Decimal degrees |
| `ip` | `string` | Local Wi-Fi IP address of ESP8266 | IPv4 |
| `timestamp` | `number` | Epoch millisecond timestamp | ms |

## 4. Strict Medical Data Integrity Rules & Physical Sensor Limitations

1. **MAX30100 Optical Signals are NOT Pre-Calculated Heart Rate or SpO2**:
   - The MAX30100 registers photodiode reflection counts (`maxIR`, `maxRED`).
   - The backend **strictly avoids fabricating** synthetic heart rate (`hr = null`) or SpO2 (`spo2 = null`). Values remain strictly `null` unless processed by an authentic mathematical extraction algorithm.
2. **DHT11 and BMP280 Temperatures are Ambient Readings**:
   - These sensors measure environmental ambient / case air temperature, not core human body temperature.
3. **Blood Pressure (NIBP) is Completely Absent**:
   - The sensor board possesses no inflatable cuff, oscillometric transducer, or NIBP module.
   - `bpSys` and `bpDia` are strictly `null`.
4. **AD8232 ECG Raw ADC Values**:
   - AD8232 outputs analog voltages centered at ~1.65V (ADC value ~512 on a 10-bit converter). It produces waveform morphology, not automated clinical diagnostic conclusions.
5. **MQ-135 Digital Signal**:
   - Indicates environmental air hazard / smoke alert via a digital comparator, not a clinical breathalyzer.
6. **Alert Classification**:
   - System alerts are categorized as **monitoring, hardware, or environmental alerts**, never definitive medical diagnoses.

## 6. SQLite Database Schema Mapping (`sensor_logs`)

When persisted to SQLite, the normalized payload is inserted into the `sensor_logs` table:

| Table Column | Source Field in Normalized Payload | SQLite Data Type | Constraints / Defaults |
| :--- | :--- | :--- | :--- |
| `id` | Auto-incremented primary key | `INTEGER` | `PRIMARY KEY AUTOINCREMENT` |
| `patient_id` | `patientId` | `INTEGER` | Foreign key referencing `patients(id)` |
| `hr` | `heartRate` (`null`) | `INTEGER` | `DEFAULT NULL` |
| `bp_sys` | `bpSys` (`null`) | `INTEGER` | `DEFAULT NULL` |
| `bp_dia` | `bpDia` (`null`) | `INTEGER` | `DEFAULT NULL` |
| `spo2` | `spo2` (`null`) | `INTEGER` | `DEFAULT NULL` |
| `temp` | `temp` (Display °F) | `REAL` | `DEFAULT NULL` |
| `timestamp` | `timestamp` (Unix epoch ms) | `INTEGER` | Not null |
| `health_score` | `healthScore` (0–100) | `INTEGER` | `DEFAULT NULL` |
| `humidity` | `humidity` (% RH) | `REAL` | `DEFAULT NULL` |
| `pressure` | `pressure` (hPa) | `REAL` | `DEFAULT NULL` |
| `ecg_val` | `ecg.value` (ADC 0–1023) | `INTEGER` | `DEFAULT NULL` |
| `mq135` | `mq135` (`"NORMAL"` / `"ALERT"`) | `TEXT` | `DEFAULT NULL` |
| `gps_lat` | `gps.latitude` | `REAL` | `DEFAULT NULL` |
| `gps_lng` | `gps.longitude` | `REAL` | `DEFAULT NULL` |
| `raw_payload` | `JSON.stringify(normalizedPayload)`| `TEXT` | `DEFAULT NULL` |
| `dht_temp` | `dhtTemp` (°C) | `REAL` | `DEFAULT NULL` |
| `bmp_temp` | `bmpTemp` (°C) | `REAL` | `DEFAULT NULL` |
| `max_ir` | `maxIR` (16-bit count) | `INTEGER` | `DEFAULT NULL` |
| `max_red` | `maxRED` (16-bit count) | `INTEGER` | `DEFAULT NULL` |
| `device_ip` | `deviceIp` | `TEXT` | `DEFAULT NULL` |
| `ai_risk_level` | `ai.risk_level` | `TEXT` | `DEFAULT NULL` |
| `ai_anomaly_score` | `ai.anomaly_score` | `REAL` | `DEFAULT NULL` |
